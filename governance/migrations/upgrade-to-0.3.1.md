## 这版改了什么

审核写不进指定文件时，回复第一句是「没有写入」加上该路径，不能再用对话长文冒充已经追加。写不进时，同一轮改落到当前工作区的 `outputs/codeplan/{plan_id}/B{n}.md`。

人在本场指出每一名在审 B 的一轮全文或文件，该轮是「可以执行」，对照修订等于当前 revision，并说出「开始按方案执行」之后，Agent A 按方案改代码。方案末尾还没有这一轮，不再停住。只有格式样例、没有可核对的一轮、或结论是「不可执行」时，仍然不改代码。

指定文件上本来就有通过轮次时，拍板后改代码的做法不变。

## 使用者要做什么

- [x] 用新 zip / 新目录替换已安装的 Skill
- [x] 无需迁移工作区（默认）
- [x] 其他：已有的 `outputs/codeplan/` 不用改，也不删除。已发出方案的「交给审核」不会自动更新。要让旧方案上的 B 看见新句子，由 Agent A 原样重抄第 10 节，revision 不加

## 不兼容说明

触发短语不变。指定文件上已经写有通过轮次的方案，仍然等人说「开始按方案执行」才改代码。

## 回滚

回到上一版分发包，对照 `governance/baselines/0.3.0/`。已生成的 `outputs/codeplan/` 不会随技能回滚自动删除。
