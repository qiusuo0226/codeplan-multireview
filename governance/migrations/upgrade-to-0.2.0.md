## 这版改了什么

多审变成可执行规则。审核人数由人指定，至少 1 名，不再理解成固定两名。每个 Agent B 只写自己的章节，每一轮自己重读磁盘上的最新代码。全部在审 B 的最新一轮都是「可以执行」之后，人说出「开始按方案执行」，才由 Agent A 按方案正文改代码。Agent B 不改方案，也不写代码。

业务方案写在所服务工作区的 `outputs/codeplan/`。

## 使用者要做什么

- [x] 用新 zip / 新目录替换已安装的 Skill
- [x] 无需迁移工作区（默认）
- [x] 其他：若工作区里已经有人手工建的 `outputs/codeplan/`，本版不改它，也不删除。不要它时自行删掉

## 不兼容说明

不再把审核人数理解成两个。人数必须由人指定。拍板改业务代码的口令是「开始按方案执行」。

## 回滚

回到上一版分发包，对照 `governance/baselines/0.1.0/`。已生成的 `outputs/codeplan/` 不会随技能回滚自动删除。
