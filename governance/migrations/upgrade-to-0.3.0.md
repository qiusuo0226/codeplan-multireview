## 这版改了什么

标准方案改成十节。代码仓是允许阅读的根路径。修改空间是允许修改的文件，必须落在代码仓里面。问题要写现象、语境、佐证和推理。多个问题改到同一个文件时，执行里该文件只有一个步骤。

Agent A 必须安装本技能。Agent B 不要求安装。B 的工作说明在方案的「交给审核」里。追加格式是 `## 第N轮`，结论下一行只能是 `可以执行` 或 `不可执行`。

## 使用者要做什么

- [x] 用新 zip / 新目录替换已安装的 Skill
- [x] 无需迁移工作区（默认）
- [x] 其他：已有的 `outputs/codeplan/` 不用改，也不删除。下次新写的方案按十节

## 不兼容说明

触发短语不变。已经写好的方案目录不用改。新方案如果仍用旧的六节，或者没有修改空间，不能交给审核。

## 回滚

回到上一版分发包，对照 `governance/baselines/0.2.1/`。已生成的 `outputs/codeplan/` 不会随技能回滚自动删除。
