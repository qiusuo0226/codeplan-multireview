# 示例：不先问人数

你说要出方案，但没说几名 B。助手不先问人数。它不预建 B 文件，也不自己定成 2 名，也不定成任何别的人数。同意之后就写方案正文。

> 假例子：还是林夏的 `local-notes`。她已经同意要方案。

```mermaid
    AI->>You: 方案路径。要审核请另开对话
```

### 同意之后就写

**你**

**助手**

> 方案在 `outputs/codeplan/CP-20261004-001/a-body.md`。`reviewers` 是空名单。没有预建 B 文件。代码还没改。
