# Impact Analysis

## CR ID

CR-20261003-001

## Summary

把代码方案多审从占位描述写成可执行规则：审核人数由人指定，每个 Agent B 分章独立审核并每轮重读磁盘上的最新代码，全部最新一轮为「可以执行」且人说出「开始按方案执行」之后，只由 Agent A 改代码。版本从 0.1.0 到 0.2.0。

## Compatibility

- [ ] 不影响已安装的旧版使用者
- [x] 需要使用者重装 Skill
- [ ] 需要工作区迁移（默认无）

已安装 0.1.0 的人要换上 0.2.0 的包。已有项目不必改文件。人下次同意出方案时，才在所服务工作区懒建 `outputs/codeplan/`。已生成的方案目录可自行删除。
